# Evidence-Based Research & Reports

An open skill for applied research, source evaluation, analysis, and clear PDF reports.

Ask a research question. The skill selects a suitable method, checks evidence, and prepares a report in the language of your request.

**Research areas:** business, technology, science and health, economics and finance, society and education, law, engineering, and data analysis.

## Use

Install the skill in a compatible AI environment, then ask it to research a topic, compare options, or analyze data. Add a location, time period, or other constraints when they matter.

## PDF reports

Install the dependencies with `pip install -r requirements.txt`. The renderer also needs fonts that support the report language. Right-to-left languages require the shaping packages listed in the requirements file.

## Development

Install test dependencies with `pip install -r requirements-dev.txt`, then run `pytest`.
