# User-provided data analysis

Use when the user supplies spreadsheets, tables, datasets, reports, or research results.

1. Identify file types, structure, units, definitions, time span, population, and intended question.
2. Check missing values, duplicates, invalid entries, outliers, inconsistent units, and sampling. Check data leakage only when building or evaluating predictive models.
3. Preserve raw data; document cleaning and transformations.
4. Choose descriptive, comparative, statistical, or qualitative methods suited to the data and question.
5. Verify calculations and code. State sample sizes, denominators, exclusions, assumptions, and uncertainty.
6. Distinguish what the dataset shows from what it cannot establish. Do not infer causation from observational data without a suitable design.
7. If external benchmarks are used, document their source and comparability.

Report data provenance, methods, key results, limitations, and reproducible calculations. Do not fabricate missing records or silently repair ambiguous values.
